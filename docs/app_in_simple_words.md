About app in simple words : 

App is similar to rive but basic version and basic features
User create a project in which it has 1 drawing board
1 drawing board can have multiple components 
component can be any shaped geometry which is possible like triangle, polygon (drawn by placing just random points) etc, 

There is bottom bar called animation which is timeline bar
in which there would time line for every component added and over the time line for every component we can click on any point and we can change the position of the element so from these tapped points and componente postions and component motions can be shown over timeline in linear way as of now


This is basic and core feature of the app
